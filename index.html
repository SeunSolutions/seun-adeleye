Cloud Data Engineering

Healthcare Data Lakehouse on AWS

Designed and built an end-to-end medallion-architecture data lakehouse on AWS using synthetic HIPAA-style patient records. Landed raw CSVs in S3 (bronze), cleaned with Glue ETL jobs into Parquet (silver), and built gold tables for clinical analytics. Enforced column-level access controls with Lake Formation and orchestrated pipeline steps with Step Functions and CloudWatch monitoring.
